# Proyecto Final - Sistema Transaccional (Login + 2FA)

Proyecto academico que simula el proceso de entrada y validacion de un usuario
a un sistema transaccional, integrando control de versiones con Git/GitHub y
buenas practicas de seguridad web.

## Funcionalidades
- Registro de usuario
- Login con usuario y contraseña
- Verificacion en 2 pasos mediante codigo enviado al celular (simulado)
- Bloqueo temporal tras intentos fallidos
- Expiracion del codigo OTP

## Tecnologias
- PHP + MySQL (XAMPP)
- HTML / CSS

## Instalacion local (XAMPP)
1. Copiar la carpeta del proyecto a `C:\xampp\htdocs\`
2. Importar `sql/estructura.sql` en phpMyAdmin
3. Iniciar Apache y MySQL desde el panel de XAMPP
4. Abrir `http://localhost/proyecto-final-seguridad/login.php`
